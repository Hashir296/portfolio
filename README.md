# Hashir Cinematic Portfolio (Old Money Edition)

Next.js 14 App Router · Framer Motion · GSAP ScrollTrigger · Lenis · AI assistant

## Run

```bash
cd cinematic
npm install
npm run dev
```

Open http://localhost:3000

## Environment

Copy `.env.local.example` → `.env.local` and add `ANTHROPIC_API_KEY` for Claude replies.
Without a key, the chat widget still answers from embedded profile knowledge.

## Assets

- Portrait: `public/portrait.png`
